## Primary sources checked by Astra

- [NEAR callback failures](https://docs.near.org/smart-contracts/security/cross-contract-calls/callback-failures):
  callbacks are separate receipts, their failure does not undo earlier receipts, and they are
  not automatically retried. A pending payout whose callback never completed must stay
  encumbered; blindly retrying the token transfer could pay twice.
- [NEAR storage cost attacks](https://docs.near.org/smart-contracts/security/storage): charge
  measured state growth, bound allocations, and define excess deposits and storage refunds.
- Pinned near-sdk5.29.1 ed25519_verify/testing_env documentation could not be fetched through
  the web tool. The designer checked latest5.30.0, which does not prove the pinned APIs. Claude
  must verify by compiling the pinned version; do not silently upgrade dependencies.
